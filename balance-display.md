# Synth sETH Token – Balance Display Narrative

**Network:** Ethereum Mainnet  
**Token:** Synth sETH Token  

## Balance Display
- Page shows **only token balance** from connected wallet  
- No price, USD value, chart, or simulated/test price  
- Purpose: **verify token recognition and wallet integration**  
- Connects via MetaMask or WalletConnect  
- **Token Balance Viewer** is the name of the page; no “dApp”, “interface”, or “dashboard” terminology  

## Displayed Information
- Logo  
- Token name  
- Symbol  
- Network  
- Contract address  
- Balance read from wallet  

## Notes
- Total supply and balances remain consistent with contract  
- No external price data or oracle involved  
- Page exists only as a **read-only balance viewer** for reviewers
